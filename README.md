# 📐 Radius Ölçek (Radius Gauge)

![Lisans](https://img.shields.io/badge/Lisans-MIT-blue.svg)
![Durum](https://img.shields.io/badge/Durum-Aktif-success.svg)

**Radius Ölçek**, kavisli yüzeylerin ve köşe kavislerinin (radius) doğru bir şekilde ölçülmesi, tespit edilmesi veya 3D baskı projeleri için referans alınması amacıyla geliştirilmiş pratik bir araçtır.

> 🌐 **Canlı Demo:** [Proje Linki](https://mryusufcan.github.io/radius-olcer)

## ✨ Özellikler

*   **Hızlı Kavis Tespiti:** Çeşitli yarıçap ölçülerini dijital ortamda veya pratik kullanımda hızlıca karşılaştırma imkanı.
*   **3D Baskı ve Atölye Uyumluluğu:** Özellikle tasarım ve imalat süreçlerinde kavis ölçümünü kolaylaştıran pratik yaklaşım.
*   **Kullanıcı Dostu Arayüz:** Sade, anlaşılır ve işlevsel tasarım.

## 🚀 Kurulum ve Kullanım

Projeyi yerel ortamınızda incelemek veya geliştirmek için aşağıdaki adımları takip edebilirsiniz:

1. Bu depoyu bilgisayarınıza klonlayın:
   ```bash

```

2. Proje dizinine gidin:
```bash
cd radius-olcer

```


3. Dosyaları bir web tarayıcısı üzerinden çalıştırarak kullanmaya başlayabilirsiniz.
